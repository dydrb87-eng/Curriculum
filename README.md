# 상지대관령고등학교 - 선택과목 그룹핑 & 수강신청 업무 자동화 시스템

고교학점제 및 선택교육과정 수강신청 결과를 정밀 분석하고, 충돌을 최소화하는 선택과목 그룹핑·분반 시뮬레이션 및 교육행정 서식 엑셀 생성을 자동화하는 웹 애플리케이션입니다.

별도의 설치나 서버 실행 없이 **웹 브라우저에서 바로 사용 가능한 순수 웹(Front-end) 버전**입니다.

## 🌐 웹 접속 및 사용 방법 (Web App)
- **웹 서비스 주소**: [GitHub Pages로 즉시 실행하기](https://566dydrb87-cloud.github.io/sangji-course-registration-automation/)
- 토큰이나 계정 인증 없이 웹 브라우저(크롬, 엣지, 웨일 등)에서 바로 접속하여 엑셀 파일을 업로드하고 작업할 수 있습니다.

## 📌 핵심 기능 안내

### 1단계: 수강신청 현황 매트릭스 & 분석
- **엑셀 원천 데이터 자동 파싱**: 구글 설문지, 나이스 수강신청 결과 엑셀 파일을 드래그 앤 드롭으로 즉시 분석
- **학기별(1학기/2학기) 선택 현황 매트릭스**: 학생별 선택 과목 및 과목별 누적 신청 인원 실시간 집계
- **개설·폐강 기준 인원 필터링**: 기준 인원 이하 소인수 과목 자동 감지 및 시각적 음영 하이라이트
- **나이스 이수 이력 교차 검증 (중복 신청 방지)**:
  - 기이수 학생 명부와 대조하여 미신청 학생 자동 탐지
  - 기이수 과목 중복 수강신청 자동 검출 및 `과목명(학년-학기)` 형식(예: `실생활 영어 회화(2-1)`) 표기
- **과목별 개설·폐강 현황표 엑셀 다운로드**:
  - 1학기 및 2학기 현황을 한 시트에 상하로 통합 구성
  - **A4 1페이지 인쇄 최적화** (동적 인쇄 영역 `Print_Area` 자동 계산 및 `fitToPage: true` 설정)
  - 파일명 뒤 다운로드 날짜 자동 기입 (`_YYMMDD` 방식)

### 2단계: 선택과목 그룹핑 & 분반 시뮬레이터
- **공평한 최적화 알고리즘 (Fair Optimization Engine)**:
  - **Fisher-Yates 무작위 셔플**: 특정 번호대 학생에게 충돌이 누적되는 편향 완전 제거
  - **동시 선택 매트릭스(Co-occurrence Matrix) 캐싱**: 탐색 속도를 극대화하여 새로고침 시마다 신속하고 다양한 최적해 도출
  - **지능형 다분반 배정**: A/B 분반 과목 선택 학생들을 인원 균형과 타 과목 충돌 회피 조건에 맞춰 스마트 배정
- **군별 그룹 수 설정 & 과목 고정(Pinning)**: 교무실 교육과정 편제 정책에 맞춘 유연한 그룹 설정
- **시간표 편성 결과 및 학생별 시간표 엑셀 다운로드**: 학교 현장에 즉시 제출 가능한 표준 교육행정 엑셀 서식 자동 서식화 생성
